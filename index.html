样例该有的样子，它都保留

不是简单截断，而是把目录结构与文件形态 1:1 搬进样例集——拿去测试、演示、联调，都像真数据。

.xlsx多 Sheet 全保留，名称与顺序不变 .xls多 Sheet 全保留，名称与顺序不变 .csv自动识别并保持编码 / 分隔符 / 换行符 .json / .jsonl / .parquet后续版本规划

目录 1:1 镜像

目标目录 1:1 镜像源目录结构（含空文件夹），同名同格式原位对照，拿到哪层都对应得上。

几十 GB 不卡死

大文件流式读取头部数据，只碰文件开头，几十 GB 的文件也能秒级出样。

实时预览 所见即所得

界面实时预览表头与前若干行，导出前就知道样例长什么样。

全局 + 单文件两级行数

抽样行数两级可控：全局默认值之外，可对单个文件单独指定；填 0 即仅保留表头。

递归扫描 按格式过滤

递归扫描源目录、按格式过滤；非数据文件可跳过，也可原样复制保持目录完整。

进度与汇总 清清楚楚

实时进度、逐文件日志、体积缩减汇总，一次导出多少、省了多少，一目了然。
